# Aula 01 — Java Básico

## Visão geral
Nesta aula foram cobertos os fundamentos da linguagem Java: sintaxe básica, tipos primitivos e referências, estruturas de controle, métodos, arrays e a execução de programas Java a partir do método `main`.

## Objetivos de aprendizagem
- Conhecer a sintaxe básica de Java e o ciclo de compilação/execução.
- Trabalhar com tipos primitivos, operadores e expressões.
- Controlar fluxo com `if`, `switch`, `for`, `while` e `do/while`.
- Definir e invocar métodos e entender passagem de parâmetros.
- Manipular arrays e coleções básicas.

## Conceitos essenciais
- Tipos primitivos: `int`, `long`, `double`, `float`, `boolean`, `char`, `byte`, `short`.
- Tipos por referência: `String`, arrays e objetos (classes).
- Variáveis: declaração, inicialização e escopo.
- Operadores: aritméticos, relacionais, lógicos e de atribuição.
- Controle de fluxo: `if/else`, `switch`, laços `for`, `while`, `do/while`.
- Arrays: declaração, inicialização e iteração.
- Método `main`: ponto de entrada `public static void main(String[] args)`.


## Como compilar e executar (terminal)
```bash
# compilar
javac OlaMundo.java

# executar
java OlaMundo
```
